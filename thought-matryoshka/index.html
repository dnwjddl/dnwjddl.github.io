Thought Matryoshka (working title)

Prefix-Valid Latent Video Thoughts for Anytime Multimodal Reasoning

Research plan · 작성 2026-08-23 · 출발점: Ponder-B · 관련 서베이: dynamic visual token comparison

비디오는 LLM에 들어가기 전에 이미 생각 가능한 상태로 접혀 있어야 한다. Thought Matryoshka는 영상을 수천 개 patch token이 아니라 중요도 순으로 정렬된 latent thought z1...zM로 바꾼다. 가장 중요한 조건은 하나다: 어떤 prefix를 잘라도 완성된 reasoning state여야 한다. z1은 한 문장짜리 상황 이해, z1:z8은 줄거리, z1:z64는 세부 지각까지 담는다.

1Overview

2Abstract (초안)

Video LLMs inherit the wrong interface from vision transformers: they pass thousands of patch tokens to a language model, then ask the language model to discover which fragments matter for reasoning. Token pruning and resampling reduce this cost, but they still treat the video representation as an unordered budget of visual evidence; choosing the budget remains an external systems decision. We propose Thought Matryoshka, a prefix-valid latent video interface for anytime multimodal reasoning. A lightweight ordered thought reader maps dense video features into a sequence of latent thoughts, sorted by marginal utility. The LLM consumes only a prefix of this sequence, and every prefix is trained to be a complete reasoning state through nested prefix supervision: random-prefix answer likelihood, distillation from full-token teachers, marginal-utility ordering, and anti-collapse coverage losses. As a result, a single question-agnostic video encoding supports multiple operating points — one thought for global gist, a few thoughts for storyline, dozens for fine-grained temporal evidence — without recomputing query-specific latent reasoning. This turns video compression from selecting fewer patches into learning an anytime hierarchy of non-verbal thoughts.

국문 요지. 기존 압축 방법은 "어떤 visual token을 남길까"를 푼다. Thought Matryoshka는 질문을 바꾼다: LLM이 읽어야 하는 비디오 표현은 애초에 patch가 아니라 latent thought의 prefix여야 한다. 학습 중 매번 다른 prefix 길이 k를 잘라 앞 z1:zk만으로 답하게 만들면, 모델은 중요한 정보를 앞 slot으로 밀어 넣는다. 그래서 추론 시 z1, z1:z8, z1:z64가 각각 다른 예산의 완성된 비디오 이해가 된다.

Oral급으로 가져갈 핵심 주장
Interface shift
우리는 visual token compression이 아니라 visual-to-thought transduction을 제안한다. LLM의 입력 단위가 patch evidence에서 latent reasoning state로 바뀐다.
Prefix-validity
토큰 개수를 정하는 별도 heuristic 없이, 모든 prefix가 유효한 표현이다. 이것이 fixed resampler, pruning, top-k token selection과 가장 큰 차이다.
Amortized video memory
thought는 질문 독립적으로 한 번 계산된다. 같은 긴 영상에 여러 질문을 던질수록 query-conditioned latent reasoning이나 pruning보다 비용 이득이 커진다.

3Method

3.1 Ordered Thought Reader

  • Input. 비디오를 일정 segment로 샘플링하고 pretrained vision tower에서 dense feature X ∈ R^(T×P×d)를 얻는다. 초기 버전은 host encoder와 LLM을 freeze하고, thought reader와 projector만 학습한다.
  • Thought queries. M_max=64개의 learnable query q1...qM가 spatio-temporal feature에 cross-attention한다. slot index embedding은 coarse-to-fine bias를 갖고, 앞 slot은 넓은 시간 범위, 뒤 slot은 좁은 residual detail에 붙도록 유도한다.
  • Timestamp. 각 thought의 attention distribution에서 soft center와 span을 추출해 M-RoPE 좌표 또는 time embedding으로 LLM에 넘긴다. event boundary detector 없이도 z_i@t_i가 생긴다.
  • LLM interface. projector가 thought를 LLM embedding space로 보내고, 입력은 [VIDEO_THOUGHT] z1 ... zk [/VIDEO_THOUGHT] question 형태가 된다. raw patch token은 기본 경로에서 LLM에 들어가지 않는다.

3.2 Nested Prefix Training

핵심은 thought slot을 "나열"하는 게 아니라 정렬시키는 것이다. 매 step prefix 길이 k를 log-uniform하게 샘플하고, LLM은 앞 k개 thought만 본다. 뒤 slot이 언제든 잘릴 수 있으므로, 중요한 정보는 앞쪽으로 이동한다.

L = E_k [ CE(y | z1:zk, q) + α KL(p_teacher || p_k) ] + β L_order + γ L_div + δ L_coverage

  • Random-prefix answer CE. k∈{1,2,4,8,16,32,64}를 랜덤 샘플해 모든 budget에서 답변이 가능하게 한다.
  • Full-token teacher distillation. full visual-token host 또는 high-budget thought model의 answer distribution을 teacher로 사용한다. 낮은 budget prefix가 "어떤 정보를 먼저 담아야 하는지"를 배운다.
  • Marginal utility ordering. z_i를 추가했을 때의 loss 감소가 앞 slot에서 더 크도록 monotone utility regularization을 둔다. 뒤 slot은 앞 prefix가 놓친 residual detail을 담당한다.
  • Diversity and coverage. slot collapse를 막기 위해 thought 간 cosine similarity를 벌점화하고, attention coverage가 시간 전체를 적당히 덮도록 한다. 단, coverage는 강제 균등이 아니라 질문 독립 video memory를 위한 약한 prior로 둔다.

3.3 Inference Modes

Mode사용 prefix목적결정 규칙
Budget mode z1:zk 서빙 비용을 고정해야 할 때 시스템이 k=4/8/16/32를 지정. 가장 단순하고 baseline 비교에 좋음.
Novelty mode 자동 절단 영상별 내용 밀도에 맞춤 slot energy, attention entropy, residual novelty가 threshold 아래로 떨어지는 지점에서 cut.
Confidence mode 점진 prefix 어려운 질문에만 더 읽기 작은 prefix로 답변 entropy가 높거나 self-consistency가 낮으면 더 긴 prefix로 재-prefill.
Multi-query cache 한 번 계산한 z1:zM 재사용 긴 영상에 여러 질문 비디오 thought cache를 저장하고 질문마다 prefix만 선택. amortization claim의 핵심.

Positioning 한 줄

Token compression은 LLM에게 덜 보이기이고, decode-time latent reasoning은 LLM이 덜 말하며 생각하기다. Thought Matryoshka는 둘 사이의 빈칸: encoder가 먼저 생각을 만들어두고, LLM은 필요한 만큼만 읽기.

5실험 계획

E1 — Main Pareto: accuracy vs prefill tokens

주장: 1/4/8/16/32/64 thought prefix가 full visual-token host 대비 훨씬 낮은 prefill에서 경쟁력 있는 성능을 낸다.

  • Benchmarks: VideoMME, MLVU, LongVideoBench, MVBench, TempCompass, VideoMathQA, MMVU.
  • Baselines: full tokens, fixed Perceiver-style resampler, LLaMA-VID류 fixed token, FastVID/VisionZip/pruning 계열, text-note baseline(Scribe/LLoVi식), VideoLatent류 output-side latent.
  • 핵심 plot: x축 prefill token 또는 TTFT, y축 accuracy. 모든 점은 k prefix 하나로 생성.

E2 — Prefix validity and monotonicity

주장: 같은 thought sequence의 prefix가 길어질수록 성능이 부드럽게 증가하고, 특정 budget에 overfit되지 않는다.

  • z1, z1:z2, z1:z4, ..., z1:z64 curve를 모든 벤치마크에서 보고.
  • tail-drop 제거, fixed-k training, unordered slots와 비교해 prefix cliff와 slot scrambling을 측정.
  • prefix calibration: 낮은 prefix에서 답변 confidence가 실제 정답률과 맞는지 평가.

E3 — Multi-query amortization

주장: 질문 독립 thought cache는 긴 영상/다중 질문 setting에서 query-conditioned 방법보다 시스템적으로 유리하다.

  • 같은 비디오에 1, 5, 20, 100개 질문을 던지는 비용 곡선: encoding cost, prefill cost, TTFT, memory.
  • VideoLatent/DyLaR류는 질문마다 reasoning latent가 필요하고, Thought Matryoshka는 video thoughts를 재사용한다는 차이를 정량화.

E4 — Thought surgery

주장: thought는 단순 압축 artifact가 아니라 reasoning unit이다.

  • Remove: z_i 하나를 제거했을 때 어떤 질문군이 무너지는지 측정.
  • Swap: 인접 thought 순서를 바꾸면 temporal/order 질문이 선택적으로 악화되는지 확인.
  • Probe: thought에서 action, object, place, temporal span, OCR 필요성 등을 linear probe로 복원.
  • Attention map: early slot은 전역 줄거리, late slot은 세부 사건/작은 물체/OCR에 집중하는지 시각화.

E5 — Ablations

  • Loss: prefix CE only / +teacher distill / +marginal utility / +diversity / +coverage.
  • Architecture: parallel cross-attention vs residual sequential readout, slot count M_max, thought dimension, temporal span embedding.
  • Training schedule: frozen LLM vs projector LoRA vs vision adapter LoRA.
  • Cut policy: fixed budget, novelty threshold, confidence-adaptive progressive prefix.

6구현 계획

Stage 0 — cheap prototype
  • Host: Qwen2.5-VL-7B 또는 LLaVA-OneVision-7B.
  • Vision features는 frozen으로 저장해서 thought reader 학습을 빠르게 반복.
  • M_max=64, 2-layer cross-attention reader, 2-layer projector.
  • QA supervision만으로 prefix CE curve를 먼저 확인.
Stage 1 — teacher-distilled model
  • Full-token host의 logits / hidden state를 teacher로 저장.
  • log-uniform prefix sampling으로 k=1...64 동시 학습.
  • 각 prefix budget별 Pareto curve를 baseline과 비교.
Stage 2 — ordering 강화
  • marginal utility loss와 residual readout variant 추가.
  • slot duplication을 diversity, attention coverage, prototype separation으로 제어.
  • Thought surgery 분석으로 "진짜 thought인가" 검증.
Stage 3 — system claim
  • multi-query cache, confidence-adaptive prefix, TTFT 측정.
  • output-side latent reasoning과 결합해 입력/출력 비용의 곱셈 이득 확인.
  • 긴 영상 streaming cache로 확장 가능성 제시.

7리스크와 방어선

  • R1 Slot order가 안 생김. Tail-drop만으로 부족하면 marginal utility loss, prefix-wise teacher KL, slot-index dropout을 추가한다. 핵심 metric은 prefix monotonicity.
  • R2 모든 thought가 비슷해지는 collapse. Diversity loss만 믿지 말고, attention coverage와 residual readout ablation을 함께 둔다.
  • R3 OCR/counting 등 세부 지각 질문에서 손실. Late slot이 detail specialist가 되는지 probing하고, 필요하면 confidence mode에서 원본 visual token 재열람을 optional extension으로 둔다.
  • R4 "그냥 resampler 아닌가?" 공격. Fixed resampler + same slot count + same training data와 정면 비교하고, prefix-validity/Thought surgery/multi-query amortization을 차별 증거로 세운다.
  • R5 질문 독립 representation이 QA supervision에 과적합. held-out task family와 paraphrase/multi-query split을 따로 만들고, teacher distillation 비중을 높여 answer-label shortcut을 줄인다.
한 문장 버전: Thought Matryoshka learns a reusable, prefix-valid hierarchy of latent video thoughts, so the LLM can reason from as many thoughts as the budget allows instead of rereading visual patches. · 관련 축: Matryoshka Representation Learning의 nested representation, TokenLearner의 learned tokenization, Flamingo의 learned visual resampling, Ponder-B의 ordered thought sketch를 결합하되, 최종 claim은 "prefix-valid latent thoughts as the video-to-LLM interface"로 분리한다.
